# Studio Context

## Glossary

### Studio chat state

The local conversation state for Studio chat: the active chat session, current artifact id, chat status, error state, and the messages/parts produced as a provider run streams.

Studio chat state is distinct from provider execution. Provider execution starts, aborts, and streams events from Pi or Cursor; Studio chat state decides how those events become the conversation snapshot shown to the renderer.
