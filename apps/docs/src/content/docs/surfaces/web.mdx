Use the [dashboard](https://dashboard.getdesign.app) to generate a `design.md` without installing the CLI or SDK. The [marketing site](https://www.getdesign.app) shows an animated sample, not a live run.

## Setup

1. Sign in through WorkOS.
2. Save your Daytona and OpenAI keys in Account.
3. Paste a public site URL to start a visual run.

Both keys are required before a visual run starts. V1 has no getdesign API key and no getdesign run billing. You pay Daytona for browser capture and OpenAI for model usage. Costs and run duration vary by site.

## What you get

A generated `design.md` describing the site's palette, typography, layout, and components. You can follow run progress and copy or download the result.
