`@getdesign/cli` runs locally on Bun. Set `DAYTONA_API_KEY` and `OPENAI_API_KEY` in your shell before starting a visual run. No WorkOS token or getdesign API key is needed for local execution. You pay the providers directly.

## Install

```bash
bun add -g @getdesign/cli
```

or run ad-hoc:

```bash
bunx @getdesign/cli https://stripe.com
```

## One-shot

```bash
bunx @getdesign/cli https://stripe.com
bunx @getdesign/cli https://stripe.com --out stripe.design.md
```

Without `--out`, output goes to `./getdesign-runs/<slug>/design.md`. Progress goes to stderr. The CLI requires a URL and does not provide an interactive REPL. Node support is not promised for V1.

## Flags

| Flag        | Description                                |
| ----------- | ------------------------------------------ |
| `--out`     | Write the result to a file path.            |
| `--site-name` | Override the detected site name. |
| `--text-only-fallback` | Accept degraded output if visual capture is unavailable. |
| `--version` | Print the installed version.                |
| `--help`    | Show help.                                  |
