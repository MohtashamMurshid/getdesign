title: SDK
description: Run the agent in-process on Bun with typed results and progress events.

The execution SDK runs the agent in-process on your Bun server using request-scoped Daytona and OpenAI credentials. It does not call the hosted API or need a WorkOS token. You pay the providers directly.

It is not a browser or edge-runtime client. Node support is not promised for V1.

```bash
bun add @getdesign/sdk
```

## Usage

```ts
import { getDesign, streamDesign } from "@getdesign/sdk";

const options = {
  credentials: {
    daytonaApiKey: process.env.DAYTONA_API_KEY,
    openaiApiKey: process.env.OPENAI_API_KEY,
  },
};
const result = await getDesign("https://stripe.com", options);
console.log(result.markdown);

// Alternative: run with progress events instead.
for await (const event of streamDesign("https://stripe.com", options)) {
  if (event.type === "progress") console.log(event.event);
  if (event.type === "result") console.log(event.result.markdown);
  if (event.type === "error") throw new Error(event.error.error);
}
```

Each call starts a separate run. Use `getDesign` for a structured result or `streamDesign` for progress followed by a result or error. The stream does not yield Markdown chunks. Keep provider keys in server-side environment variables, never in browser code.

## Options

```ts
await getDesign("https://stripe.com", {
  ...options,
  siteName: "Stripe",
  visualRequirement: "require",
});
```
