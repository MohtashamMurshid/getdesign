## Does getdesign scrape HTML?

No. It renders the target URL in a real browser and reads computed CSS. Results reflect what users actually see.

## Can I use the output commercially?

The output describes publicly visible design choices of the target site. Respect the target's trademarks and terms. getdesign's own code is open source; see the [repository](https://github.com/MohtashamMurshid/getdesign).

## Which surface should I use?

- [Web](/surfaces/web/) to explore.
- [API](/surfaces/api/) to integrate server-side.
- [CLI](/surfaces/cli/) for scripts.
- [SDK](/surfaces/sdk/) inside a TypeScript app.
- [Skill](/surfaces/skill/) to run inside your own coding agent.

## Is there authentication?

The dashboard requires sign-in through WorkOS. Hosted design endpoints expect `Authorization: Bearer <WorkOS access token>`. There is no getdesign API key in V1. Visual API runs also need `x-daytona-api-key` and `x-openai-api-key` headers. The CLI and SDK run locally on Bun with provider credentials and do not need a WorkOS token.

## What does a run cost?

V1 has no getdesign run billing. You pay Daytona for browser capture and OpenAI for model usage. Bring your own provider keys; getdesign does not supply provider credits. Costs vary by site and provider usage. To use the web app, [sign in to the dashboard](https://dashboard.getdesign.app) and save both keys in Account.
