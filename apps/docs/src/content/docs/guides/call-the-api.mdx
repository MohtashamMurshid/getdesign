## Fetch a design.md

Set a WorkOS access token and your Daytona and OpenAI keys in your shell. V1 has no getdesign API key or run billing. You pay those providers directly.

```bash
curl "https://api.getdesign.app/v1/design?url=https://stripe.com" \
  -H "Authorization: Bearer $WORKOS_ACCESS_TOKEN" \
  -H "x-daytona-api-key: $DAYTONA_API_KEY" \
  -H "x-openai-api-key: $OPENAI_API_KEY" \
  -H "Accept: text/markdown" \
  -o stripe.design.md
```

## Pipe it straight into a file

```bash
curl -sS "https://api.getdesign.app/v1/design?url=https://linear.app" \
  -H "Authorization: Bearer $WORKOS_ACCESS_TOKEN" \
  -H "x-daytona-api-key: $DAYTONA_API_KEY" \
  -H "x-openai-api-key: $OPENAI_API_KEY" \
  > linear.design.md
```

## Use with jq for palette only

Use `format=json` for a structured result, then select the palette:

```bash
curl -sS "https://api.getdesign.app/v1/design?url=https://stripe.com&format=json" \
  -H "Authorization: Bearer $WORKOS_ACCESS_TOKEN" \
  -H "x-daytona-api-key: $DAYTONA_API_KEY" \
  -H "x-openai-api-key: $OPENAI_API_KEY" \
  | jq '.doc.palette' > stripe.palette.json
```

JSON output uses the `format=json` query parameter, not the `Accept` header. See the [API surface](/surfaces/api/) for progress streaming and error responses.
