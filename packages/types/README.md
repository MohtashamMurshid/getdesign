# @getdesign/types

Shared Zod schemas and TypeScript types for getdesign packages.

This package is primarily consumed by `@getdesign/sdk`, `@getdesign/agent`, and
internal tools. Most application developers should install `@getdesign/sdk`
instead.

## Exports

- `@getdesign/types` — common design document/result types.
- `@getdesign/types/design-doc` — `DesignDoc` schema and type.
- `@getdesign/types/design-tokens` — extracted design token schema and type.
